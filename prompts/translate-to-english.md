Translate the selected Spanish Markdown note into literary English.

Requirements:

- Preserve Markdown formatting.

- Preserve tone, ambiguity, rhythm, and intimacy.

- Do not over-explain metaphors.

- Do not modernize or flatten the voice.

- Keep titles poetic but natural.

- Create the translated file in `notes/en/` using the same filename.

- Add frontmatter linking to the original Spanish note.

Frontmatter example:

---

lang: en

original: ../es/FILENAME.md

translator: AI-assisted

status: translated-draft
