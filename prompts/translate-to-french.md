Translate the selected Spanish Markdown note into literary French.

Requirements:

- Preserve Markdown formatting.

- Preserve tone, ambiguity, rhythm, and intimacy.

- Do not over-explain metaphors.

- Do not make the prose too formal unless the Spanish requires it.

- Keep the voice literary, clear, and natural.

- Create the translated file in `notes/fr/` using the same filename.

- Add frontmatter linking to the original Spanish note.

Frontmatter example:

---

lang: fr

original: ../es/FILENAME.md

translator: AI-assisted

status: translated-draft
