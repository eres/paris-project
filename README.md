Private bilingual writing + photography project.

## Structure

- `notes/es/` original notes in Spanish

- `notes/en/` English translations

- `notes/fr/` French translations

- `prompts/` translation prompts

- `scripts/` automation helpers

## Workflow

1. Write original note in `notes/es/`

2. Mark it as ready in frontmatter:
